# Gestor de Usuarios UMG - Backend

API REST desarrollada con Node.js, Express y MongoDB para la Práctica Integradora de la Universidad Mariano Gálvez (UMG).

## Tecnologías Utilizadas
* Node.js
* Express
* Mongoose / MongoDB
* CORS / Dotenv / Nodemon

## Requisitos Previos
* Tener instalado **Node.js**.
* Tener instalado y corriendo una instancia local de **MongoDB**.

## Instrucciones de Instalación y Ejecución

1. Clonar o descargar el repositorio.
2. Instalar las dependencias del proyecto:
   ```bash
   npm install
   npm run dev
   El servidor estará corriendo por defecto en http://localhost:4000.
